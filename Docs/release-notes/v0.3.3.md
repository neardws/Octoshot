# Octoshot v0.3.3

## 中文

> **本版本起仅支持 Apple Silicon（arm64），不再支持 Intel Mac。**

### 一酱日记（M1）

- 晚间日报：默认约 22:00 汇总当天窗口与活动，可在设置中调整时间与开关 (#115, #117)
- 深度分析：本地整理时间线与摘要；可选本机 Ollama MiniCPM-V-4.7:1b 生成轻松吐槽 (#119)
- CLI：`octoshot diary`（`today` / `show` / `timeline` / `export` / `pause` / `resume` / `status` / `purge --confirm`），关键命令支持 `--json` (#121)
- MCP：只读 `diary_get_report`、`diary_get_timeline`、`diary_status`；写操作仅 `diary_pause`（不读原图）(#121)
- 加密存储；原图处理后删除；CLI/MCP 经 `octoshot://diary` 一次性 mailbox，由运行中的 App 解密回写，不碰钥匙串

### 修复与改进

- 快速访问浮窗：拖出缩略图可落到任意 App（file URL + PNG/TIFF）(#113)
- 打码：模糊/像素化越界裁剪到画布，避免溢出 (#105)
- MCP：文件结果 JSON 安全编码 (#107)
- OCR：统一结果/错误路径，修复崩溃 (#94)
- 内置 VLM：生成 token 上限、会话刷新、GPU 缓存与空闲卸载 (#96)
- 发布包改为 arm64-only，体积更小，并保留 llama 运行时符号链接 (#98)
- 导出提速：共享 CIContext、缓存打码、主线程外直接编码 (#100)
- 设置页完成简体中文本地化 (#92)
- 截图正确性与自动化相关合入（窗口排除、指针、阴影、显示器、同意提示等）

## English

> **This release is Apple Silicon (arm64) only. Intel Macs are no longer supported.**

### Yijiang Diary (M1)

- Evening report: around 22:00 by default, summarizing windows and activity; schedule and toggle in Settings (#115, #117)
- Deeper local analysis; optional on-device Ollama MiniCPM-V-4.7:1b roast (#119)
- CLI: `octoshot diary` (`today` / `show` / `timeline` / `export` / `pause` / `resume` / `status` / `purge --confirm`); stable `--json` on key commands (#121)
- MCP: read-only `diary_get_report`, `diary_get_timeline`, `diary_status`; write only `diary_pause` (no raw frames) (#121)
- Encrypted store; originals deleted after processing; CLI/MCP use a one-shot `octoshot://diary` mailbox so the running app decrypts and replies without touching the Keychain

### Fixes & improvements

- Quick Access: drag-out delivers file URL + PNG/TIFF into any app (#113)
- Redaction: clip overhang blur/pixelate to the canvas (#105)
- MCP: safer JSON encoding for file results (#107)
- OCR: single result/error path (crash fix) (#94)
- Embedded VLM: maxTokens, fresh session, GPU cache limit, idle unload (#96)
- Slimmer arm64-only releases; preserve llama runtime symlinks (#98)
- Faster export: shared CIContext, cached redaction, off-main CGImage encoding (#100)
- Settings: complete Simplified Chinese localization (#92)
- Capture-correctness and automation hardening (window exclusion, pointer, shadow, display, consent, and related fixes)
