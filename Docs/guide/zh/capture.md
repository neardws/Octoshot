# 捕获模式

## 区域捕获

从菜单或区域快捷键选择 **Capture Area**，拖选矩形后使用 **模式条**：

| 键 | 模式 |
| --- | --- |
| S | 截图 |
| R | 滚动拼接 |
| V | 视频（区域） |
| G | GIF（区域） |
| L | LaTeX 公式 |
| T | 图/表到 Clips |

## 窗口与全屏

**Capture Window** 高亮可选窗口；**Capture Fullscreen** 捕获主显示器。

## 快速访问

捕获后出现浮动缩略图，可复制、保存、标注、关闭或拖出。有本机建议时点击 **Apply** 执行。

最新截图位于堆叠的底部和最前方。点击堆叠可向上展开；点击外部或“收起堆叠”可收起。每张图片保留原有宽高比。点击 × 或拖出卡片只会将其移出面板，不会删除已保存的文件。

在 **设置 → 通用 → 快速访问 → 工具栏样式** 中，可选择默认的“图片下方”胶囊工具栏或“环形”（以悬停卡片为中心的半透明正圆叠层，直径上限为 170 点，并按可见边界缩小）。六个等角度分区依次提供复制、保存、标注、贴图、文字识别和关闭，支持悬停高亮、提示及无障碍标签。圆环以弹簧缩放和淡入淡出效果显示在卡片上方，不预留空间、不撑开间隙，也不增大面板。只有胶囊工具栏在展开悬停时利用预留空间打开间隙；折叠悬停均不移动卡片。额外的 AI、Markdown 和文件路径操作位于图片右键菜单中。

## 标注

在快速访问中打开 **Annotate**，支持箭头、形状、文字、马赛克、撤销与导出。

## 滚动截图

在滚动模式下手动滚动内容；或在 **设置 → Recording** 启用自动滚动（需辅助功能）。
